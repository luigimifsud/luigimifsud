# Cards and documents

A short card for each model and system I've built, and documents that sit beside the project pages.

These cards say what each model did and what it was measured on. They don't describe how the models are built.

## Model cards

- [Hail Mary English model](cards/hail-mary-english.md): the English model I have trained since 18 Nov 2026.
- [Hail Mary arithmetic model](cards/hail-mary-arithmetic.md): the small model in the arithmetic preview.
- [Hail Mary forecaster](cards/hail-mary-forecaster.md): the forecaster, tested on generated streams.
- [Hail Mary small exact model](cards/hail-mary-small-exact.md): the small model in the exact test, with 1,985 weights.
- [Earlier English models](cards/earlier-english-models.md): the 25 million weight model of 26 to 27 Oct 2026, and the paused run for a model of about 200 million weights.
- [Mark One 40M](cards/mark-one-40m-code.md): my 40.6 million parameter model, trained on code and prose.
- [Mark One 295M, step 199,000 snapshot](cards/mark-one-220m-code.md): the snapshot I scored against Qwen2.5-Coder-7B.
- [Mark One 295M](cards/mark-one-295m.md): my largest Mark One model, and its Python tasks.
- [Mark One Maltese](cards/mark-one-maltese.md): my 104.5 million parameter model, trained on Maltese text.
- [Forge](cards/forge.md): my early from-scratch model and the code to train it.
- [QMK and AMK](cards/qmk-and-amk.md): the learning lines before Project Hail Mary, as a whole.
- [QMK-1](cards/qmk-1.md): a learning model in the QMK line.

- [Jarvis reader](cards/jarvis-reader.md): the small local reader inside Jarvis.
