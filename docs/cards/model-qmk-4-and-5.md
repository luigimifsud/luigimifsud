# QMK-4 and QMK-5

QMK-4 was a program in my QMK line that kept reading English text in October 2026, and QMK-5 was a planned rewrite of it that stayed at the testing stage; neither has a score.

| Status | QMK-4 has rested since 22 Oct 2026, 13:46. QMK-5 never became a working model. I changed the rules for the whole line on 17 Nov 2026. |

## What it was for

QMK-4 was built on QMK-3's code. It was meant to keep building up knowledge from a continuous stream of English text, not to predict the next word, so it was never scored as a compressor.

QMK-5 was a plan, written on 5 Oct, to rewrite QMK-4 in Rust and CUDA, with a check that the rewrite behaves bit for bit the same.

## What it was trained and tested on

- QMK-4 read English text in separate runs from 14 to 22 Oct 2026.
- QMK-5 stayed at small tests: a shared code library, test labs run on 17 to 21 Oct, and five candidate versions of QMK-4's code raced against each other on 28 to 31 Oct. AMK2, my next model, was also meant as its testing ground.

## Results

- **No score exists for QMK-4.** It was not built to predict text, and there is no test of it on record that I can quote.
- **QMK-5 produced no model.** My notes disagree on whether one of the five candidates was taken up by 31 Oct, so I make no claim either way.
- **What the line came to.** Over about seven weeks, the QMK and AMK models I built under strict rules never got past reading back what they had been fed.

## Where it falls short

- Neither has a measured result.
- QMK-5 never got past its tests.
- My own records disagree on the last step of QMK-5.

## Not done yet

- QMK-4 rests. Its code was reused for QMK-5's tests up to 31 Oct.
- Nobody outside my projects has run either.
