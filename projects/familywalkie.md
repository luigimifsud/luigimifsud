# FamilyWalkie

A push-to-talk family radio for phones, with no SIM card, that uses every radio a phone has.

**Status:** built, 106 commits.

## What it is

An app that turns a family's phones into walkie-talkies. It needs no SIM card. It uses every radio the phone already has.

## Why it exists

It started as something bigger. This is what I asked for:

"I want cellular service that works without need of a phone number. I want to use LTE waves and low bandwidth waves. No is not an answer."

The project's own notes say plainly that real cellular service from an app is not buildable. So instead of pretending, it became a radio: the part of the idea that can be built.

## What I built

- The push-to-talk app.
- The code that uses every radio the phone has.
- A test suite that runs in each of four build variants.

## Results

- 106 commits (counted on 26 Nov 2026).
- 603 of 603 tests passing in each of four build variants (recorded in a commit message, not re-run).

## Where it falls short

The original ask, cellular service without a phone number, could not be built from an app, and the notes say so. What exists is a no-SIM radio, which is a smaller thing than what I set out to make.
